# 波動筆記｜選修物理 III

網站：https://jimmy980821-ops.github.io/wave-notes/

依翰林章節順序整理第一章波動（1-1～1-7）、第二章聲波（2-1～2-3）。共 10 節、30 題附解析練習、原有 2 種及新增 7 種互動演示。

## 手機與電腦同步

點「使用 Google 帳號登入」，兩台裝置使用同一帳號。未登入時先保存在瀏覽器；登入後以 Firebase 同步，每節與每題各自合併，斷線可保留待上傳變更。

使用與化學筆記相同的公開 Firebase 專案設定，但只寫入使用者文件的 `physicsWavesV1` 欄位，不改寫化學或 StudyHub 資料。原 Sites 網站採 ChatGPT 登入，兩套進度分開，不會自動搬移。

## 發布

GitHub Pages 使用 `main` 分支的根目錄，無需建置。更新 HTML/CSS/JS 後推送即可。`tests/` 為本機瀏覽器測試，以 Firebase 替身驗證同步，不寫入真實帳號。
