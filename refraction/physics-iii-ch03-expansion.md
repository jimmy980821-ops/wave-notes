## basics

### 第一眼先找什麼？用「畫、量、判」看題目

1. **畫界面與法線。** 水平水面畫直的法線；斜玻璃面的法線跟著轉。曲面（例如水滴）要在入射點畫局部切線，再畫垂線；球面的法線就是穿過球心的半徑方向。
2. **量入射角。** 從入射線與法線所夾的銳角量起。沿水面幾乎擦過，叫掠入射，入射角接近 90°。
3. **判去向。** 回原來那側是反射；穿進另一側是折射。折射不等於轉彎：垂直入射也可以透射，只是沒有偏向。

<details><summary>例題｜同一條光線，為什麼有人量到 25°、有人量到 65°？</summary><p>如果 25° 是光線與平面的夾角，65° 就是它與法線的夾角，兩者都可以量到，但只有後者是入射角。此時反射角也是 65°，反射光與平面的角仍是 25°。</p></details>

## snell

### 折射率的三種問法：角度、速率與波長

同一束單色光跨過靜止界面，若 n₂/n₁ = 1.5，代表 v₁/v₂ = λ₁/λ₂ = 1.5。這裡容易把「誰除誰」寫反：第二層折射率較大，所以它的速率、波長都應較小。角度題則是 **sin i / sin t = n₂/n₁**；注意是正弦比，不是角度比。

<details><summary>例題｜要射到哪裡？先把折射角換回水平距離</summary><p>雷射由空氣斜入 0.80 m 深的水，入射角 45°，水的 n = 4/3。先算 sin t = (3/4)sin 45° ≈ 0.530，所以 t ≈ 32.0°。在水中直角三角形的鄰邊是水深，水平偏移 x = 0.80 tan 32.0° ≈ <strong>0.50 m</strong>。若直接用 45°，就忽略了光進水後轉向。</p></details>

### 平行板：側移量怎麼量？

側移量是**兩條平行線的最短距離**：一條是入射光的直線延長，另一條是出射光。玻璃板垂直厚度為 d，玻璃內光程長度為 d/cos t；這段光路與原方向夾角 i−t，因此側移量為 **d sin(i−t)/cos t**（空氣進玻璃、兩側相同介質的情形）。

<details><summary>例題｜厚 3 cm 的玻璃板，出射光偏到哪裡？</summary><p>空氣以 60° 入射，題目給玻璃 n = √3。由司乃耳定律得 sin t = sin 60°/√3 = 1/2，因此 t = 30°。側移為 3 sin 30°/cos 30° = <strong>√3 cm</strong>，出射光仍與入射光平行。</p></details>

### 視深：兩層液體怎麼加？

由空氣近乎垂直往下看，若界面都平行，每層的視厚度分別約為其真厚度除以折射率，再把視厚度相加。例如水厚 40 cm、n = 4/3，下方玻璃厚 15 cm、n = 1.50，從上方看玻璃底面：視深 ≈ 40/(4/3) + 15/1.50 = **40 cm**，真深是 55 cm。

## tir

### 光纖：軸線角與側壁角剛好互餘

直光纖的側壁和軸線平行，側壁法線則垂直軸線。若纖芯中的光線與軸線夾角為 φ，且在包含軸線的平面中行進，打到側壁的入射角便是 90°−φ。**光線越接近軸向，撞側壁時越接近掠入射**，越容易滿足全反射。

<details><summary>例題｜纖芯 1.50、包層 1.40，與軸線夾 15° 的光會漏嗎？</summary><p>側壁入射角是 90°−15° = 75°。臨界角 sin⁻¹(1.40/1.50) ≈ 69.0°；75° 大於 69.0°，符合全反射。把 15° 直接與臨界角相比會判錯。</p></details>

### 為什麼鑽石的臨界角比水小？

同樣射向空氣，sin θc 約等於 1/n。n 大，臨界角反而小。取鑽石 n ≈ 2.42，θc ≈ **24.4°**；水的臨界角約 48.6°。同樣的內部入射角 35°，在鑽石裡有全反射，在水裡還能折射。鑽石的切面也決定哪些光能最後往觀察者方向射出。

## color

### 用同一個角度，驗算「紫光偏得多」

白光從空氣以 45° 進入某種玻璃，假設紅光 n = 1.50、紫光 n = 1.54。紅光的折射角約 28.1°、紫光約 27.3°。入射方向原本在 45°，所以兩者朝法線分別轉了約 **16.9° 與 17.7°**。結論：紫光**折射角較小**，但**轉向較多**。

### 為什麼紫光偏得多，主虹卻在內側？

稜鏡題是在比較「從原來方向轉了多少」，彩虹題是在比較「從反太陽方向量出去的角半徑」。主虹的光本來接近折返回去，偏轉越接近 180°，就越靠近反太陽方向，角半徑反而越小。紫光的主虹角約 40°，紅光約 42°，因此紫內紅外。這是兩種不同的量角起點。

## lens

### 公式為什麼長這樣？用例 5 畫相似三角形

考慮會聚透鏡成倒立實像。設物高為 H、倒立像高的大小為 H′。穿過光心的光線是同一條斜線，得到 H′/H = q/p。從物頂水平射來的那條光，在透鏡處高度是 H，過了右焦點 F 後繼續下降，所以也有 H′/H = (q−f)/f。令兩式相等並整理，就得到 **1/f = 1/p + 1/q**。帶符號的公式也能處理本章的虛像，不必為虛像背另一條。

<details><summary>例題｜屏幕固定在透鏡右側 20 cm，物體要放在哪裡？</summary><p>若 f = 8 cm，屏幕在另一側，q = +20 cm。由 1/p = 1/8 − 1/20 = 3/40 得 <strong>p = 40/3 cm</strong>，即物體應放在透鏡左側約 13.3 cm。m = −20/(40/3) = −1.5，是倒立放大實像。先用 q 的正號記錄屏幕的位置，再用 m 的負號記錄倒立。</p></details>

### 操作前先預測

把會聚透鏡的物體從 3f 移到 2f，再移到 1.5f：像會離透鏡更遠，也變大。再繼續移到 f 時，像不是「消失在焦點上」；光在像側平行，**有限距離的屏幕**接不到清晰像。越過 f 後，才改成物體同側的正立虛像。若覺得「像突然換邊」，就把這個過程想成像距先變得很大，再從另一側回來。
